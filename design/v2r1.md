# タスク指示書: `gip` への Jujutsu (jj) Change ID 抽出機能の追加

`gip` を実行した際、現在のリポジトリが Jujutsu (jj) の管理下である場合、Issueの本文（パーマリンク付近）に `Change ID` を刻印する機能を追加してください。
この機能は、通常の Git ユーザーの環境（`jj` がインストールされていない、または `jj` 管理下ではない場合）には一切影響を与えない（エラーで落ちない）ように安全に実装する必要があります。

## 1. Change ID 取得関数の追加
`src/gip/main.py`（または適切なユーティリティファイル）に、以下の関数を追加してください。

```python
import subprocess

def get_jj_change_id() -> str:
    """
    Jujutsu (jj) 環境下であるかを判定し、現在の Change ID を取得する。
    jj がインストールされていない、または jj リポジトリではない場合は空文字を返す。
    """
    try:
        # jj log を実行して現在の Change ID (@) を取得
        result = subprocess.run(
            ["jj", "log", "--no-pager", "-T", "change_id", "-r", "@"],
            capture_output=True,
            text=True,
            check=False
        )
        
        # コマンドが成功し、出力があればそれを返す
        if result.returncode == 0 and result.stdout.strip():
            return result.stdout.strip()
    except Exception:
        # jjコマンドが存在しない(FileNotFoundError)などの場合は無視
        pass
    
    return ""
```

## 2. Issue 本文（body）への組み込みロジックの修正
Issue を作成するメインループの中で `get_jj_change_id()` を呼び出し、Change ID が取得できた場合のみ、ブランチ名出力の下に Change ID を追記する処理を追加してください。

【変更イメージ】
```python
        # ... (既存のブランチ名取得処理) ...
        current_branch = get_current_branch()
        jj_change_id = get_jj_change_id()
        
        issue_body_lines.append("")
        issue_body_lines.append("---")
        issue_body_lines.append("")
        
        issue_body_lines.append(f"🌿 **Branch:** `{current_branch}`")
        
        # 追加: jj環境の場合のみ Change ID を挿入
        if jj_change_id:
            issue_body_lines.append(f"💎 **jj Change ID:** `{jj_change_id}`")
            
        issue_body_lines.append(f"🔗 [{filepath}]({file_permalink})")
```

## 3. 実装上の注意点
* `subprocess.run` は `shell=True` を使わず、リスト形式で引数を渡してください。
* この機能は「意図のサイドカー」としての追跡性を高めるためのものです。通常のGitユーザーの体験を損なわないよう、`jj_change_id` が空文字の場合は何も出力せずにサイレントに通過させてください。
