# タスク指示書: `src/gip/main.py` のIssue起票先リモートを環境変数 `GIP_ISSUE_REMOTE` で指定可能にする

## 1. 概要
`src/gip/main.py` を修正し、Issueを起票する対象のリポジトリを `gh` コマンドのプロンプト任せにする挙動を廃止します。
`direnv` 等を用いたプロジェクトごとの柔軟な設定を可能にするため、環境変数 `GIP_ISSUE_REMOTE` で指定されたリモート名（未設定時のデフォルト: `origin`）のURLを解決し、それを `gh` コマンドへ明示的に渡す仕様に変更してください。
**※注意:** リポジトリを横断して起票する場合（例: `upstream` にIssueを作り、コードは自分の `origin` にある場合）、パーマリンクがリンク切れ（404）になるのを防ぐため、「リンク生成用」と「起票用」のURLを分離します。

## 2. 対象ファイル
* `src/gip/main.py`

## 3. 実装要件

### ① 環境変数 `GIP_ISSUE_REMOTE` の導入
* プログラム引数での指定は行わず、環境変数 `GIP_ISSUE_REMOTE` の値を取得してIssueの起票先リモート名として使用してください。
* 環境変数が未定義、または空文字の場合は、デフォルト値として `"origin"` を使用してください。

### ② リモートURLの確実な解決とエラーハンドリング
* 指定されたリモート名からURLを取得する関数 `get_git_remote_url(remote_name)` を追加してください。
* `git remote get-url <remote_name>` などの実行に失敗した場合（登録されていないリモート名が指定された場合など）は、「指定されたリモート '{remote_name}' は存在しません。環境変数 GIP_ISSUE_REMOTE の設定を確認してください。」というエラーメッセージを出力し、`sys.exit(1)` で安全に終了させてください。

### ③ URLの役割の分離（パーマリンク用 vs 起票用）
* **パーマリンク用URL:** コードの実体が存在する場所として、**常に `origin`** のリモートURLからGitHubのベースURLを取得（`get_github_repo_url`）し、これを使って `file_permalink` を生成してください。
* **Issue起票用URL:** 環境変数（またはデフォルト）から決定したリモートURLを取得し、これを `gh issue create` の `--repo` 引数に渡してください。

### ④ `gh` コマンドへのリポジトリの明示（`--repo` の常時追加）
* 取得したリモートURLを用いて、**必ず** `gh` コマンドの実行時に `--repo <URL>` 引数を追加し、`gh` 側が複数リモートの存在に迷って対話プロンプトを出して停止するのを防いでください。
* 対象となる実行箇所:
  1. `get_github_repo_url()` 内の `gh repo view` コマンド
  2. `main()` 内の `gh issue create` コマンド

## 4. 実装のヒント（期待するコードのイメージ）

```python
import os
import sys

# リモートURL取得用関数の追加
def get_git_remote_url(remote_name: str) -> str:
    # 失敗した場合はエラー終了するロジック（run_cmdの例外処理など）
    # エラー時は sys.exit(1) で終了
    return run_cmd(["git", "remote", "get-url", remote_name])

# get_github_repo_url の改修イメージ
def get_github_repo_url(target_repo_url: str) -> str:
    # --repo を常に付与する
    return run_cmd(["gh", "repo", "view", "--repo", target_repo_url, "--json", "url", "-q", ".url"])

# main() 内の改修イメージ
def main():
    # ... 中略 ...
    
    # 環境変数から起票先リモート名を取得（デフォルト: origin）
    issue_remote_name = os.environ.get("GIP_ISSUE_REMOTE") or "origin"
    
    # 1. パーマリンク用URL（コードの実体がある場所 = 常に origin）
    origin_remote_url = get_git_remote_url("origin")
    permalink_repo_url = get_github_repo_url(origin_remote_url)
    
    # 2. Issue起票先URL（環境変数で指定されたリモート）
    issue_target_remote_url = get_git_remote_url(issue_remote_name)
    
    # ... 中略 ...
    
    for ... :
        # パーマリンクは origin ベースで生成
        file_permalink = f"{permalink_repo_url}/blob/{commit_hash}/{filepath}"
        
        # ... 中略 ...
        
        # Issue起票時は環境変数由来のターゲットへ
        cmd = [
            "gh", "issue", "create",
            "--repo", issue_target_remote_url,
            "--title", issue_title,
            "--body", issue_body,
            "--label", "gip"
        ]
        issue_url = run_cmd(cmd)
```
