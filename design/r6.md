# バグ修正: `gh repo view` の引数エラー

`src/gip/main.py` 内の `gh repo view` コマンドの実行において、`unknown flag: --repo` というエラーが発生しています。

`gh repo view` は `--repo` オプションを受け付けないため、対象のURL（またはリポジトリ名）をコマンドの引数として直接渡すように修正してください。

【修正のイメージ】
- 誤: `["gh", "repo", "view", "--repo", target_repo_url, "--json", ...]`
- 正: `["gh", "repo", "view", target_repo_url, "--json", ...]`
