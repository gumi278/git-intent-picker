# タスク指示書: `src/gip/main.py` のIssue起票ロジックの改善

## 1. 概要
`src/gip/main.py` を修正し、GitHub Issueに起票する際の「本文の出力形式」および「ghコマンドの引数」を以下の仕様に合わせて変更してください。

## 2. 対象ファイル
* `src/gip/main.py`

## 3. 実装要件（修正の仕様）

現在のコードの `main()` 関数内にある、Issueを起票するためのループ処理を修正します。

### ① マークダウンのコードブロック装飾の廃止とプレーンテキスト化
* `issue_body_lines` を組み立てる際、`python` のコードブロック（` ``` `）による装飾を**廃止**してください。
* 抽出されたコメントブロックの**1行目（トリガー行）は出力からスキップ**してください（1行目はタイトル生成のみに使用します）。
* 2行目以降の各行について、行頭の空白（インデント）、`#` 記号、およびその直後の空白を取り除いた「クリーンなプレーンテキスト」に変換して本文に追加してください。
  * 変換例: `line.lstrip(" \t#").lstrip(" \t")`

### ② パーマリンクから行番号指定（Line）を排除する
* 本ツールの「マーカーコメント自体はコミット履歴に残さずRollbackする」という理念上、リモートリポジトリに行番号指定リンクを張ると、該当行が存在しなかったりズレたりしていて誤解を招く原因になります。
* そのため、パーマリンクURLの末尾の `#L{block['line']}` を**削除**し、ファイル単位へのリンク（`{repo_url}/blob/{commit_hash}/{filepath}`）に留めてください。
* Issue本文のリンクテキスト部分からも `(Line {block['line']})` の記述を削除してください。

### ③ Issue起票時の自動ラベリング
* `gh issue create` コマンドを実行する引数に `--label` オプションを追加し、値として `"gip"` を渡して起票されるIssueにラベルを付与してください。

## 4. 期待する修正後のコードイメージ（抜粋）

`main()` 関数内の起票ループ部分を以下のように置き換えて実装してください（他の機能や既存実装は崩さないこと）。

```python
    for i, data in enumerate(extracted_blocks_flat, 1):
        filepath = data["filepath"]
        block = data["block"]
        
        issue_title = generate_issue_title(block["content"], author_name, filepath)
        
        # ハッシュ指定のパーマリンクURLを構築（行番号指定は誤解を招くため除外）
        file_permalink = f"{repo_url}/blob/{commit_hash}/{filepath}"
        
        # Issue本文の構成
        issue_body_lines = []
        
        # 1行目はスキップし、2行目以降のコメント記号とインデントを取り除く
        for line in block['content'][1:]:
            clean_line = line.lstrip(" \t#").lstrip(" \t")
            issue_body_lines.append(clean_line)
            
        issue_body_lines.append("") # 空行を挿入
        # リンクのテキストからも行番号指定を外す
        issue_body_lines.append(f"🔗 [{filepath}]({file_permalink})")
        
        issue_body = "\n".join(issue_body_lines)
        
        print(f"🚀 [{i}/{total_blocks}] Issueを起票中: {issue_title}")
        # --label "gip" を追加してIssueを作成
        issue_url = run_cmd([
            "gh", "issue", "create",
            "--title", issue_title,
            "--body", issue_body,
            "--label", "gip"
        ])
        created_issue_urls.append(issue_url)
```
