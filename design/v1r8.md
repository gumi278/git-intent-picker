# タスク指示書: `src/gip/main.py` にブランチ名の出力機能を追加

Issueの本文（パーマリンクの直前）に、その意図が記述された時点のGitローカルブランチ名を明記するように実装を修正してください。

## 1. ブランチ名取得関数の追加
以下の関数を `main.py` に追加してください。`git branch --show-current` を使用し、Detached HEAD状態でブランチ名が取得できないケースのフォールバックも考慮します。

```python
def get_current_branch() -> str:
    branch = run_cmd(["git", "branch", "--show-current"], check=False)
    return branch if branch else "detached HEAD"
```

## 2. Issue本文（body）への組み込み
`main()` 関数内で Issue を作成するループの前に `current_branch = get_current_branch()` を呼び出してください。
その後、Issue本文（`issue_body_lines`）を組み立てる際、パーマリンク（🔗）の直前にブランチ名のテキスト（🌿）を挿入してください。

【変更イメージ】
```python
        # ... (既存のコード) ...
        issue_body_lines.append("")
        issue_body_lines.append("---")
        issue_body_lines.append("")
        
        # 追加: ブランチ名の挿入
        issue_body_lines.append(f"🌿 **Branch:** `{current_branch}`")
        
        # 既存: パーマリンク
        issue_body_lines.append(f"🔗 [{filepath}]({file_permalink})")
```
