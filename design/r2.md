# タスク指示書: `src/gip/main.py` のIssue本文出力ロジックの修正

## 1. 概要
`src/gip/main.py` を修正し、GitHub Issueに起票する際の「マーカーコメントの表示形式」をクリーンなプレーンテキストに変更してください。

## 2. 対象ファイル
* `src/gip/main.py`

## 3. 実装要件（修正の仕様）

現在のコードの `main()` 関数内にある、Issueの本文（`issue_body_lines`）を組み立てているループ処理を以下の仕様に合わせて修正してください。

### ① マークダウンのコードブロック装飾の廃止
* 現在は `issue_body_lines = ["```python"]` と `issue_body_lines.append("```\n")` によってPythonコードブロックとして出力していますが、これを**廃止**し、プレーンテキストとして出力するようにしてください。

### ② 1行目（タイトル行）のスキップ
* 抽出された `block['content']` の**1行目（`# @author:` などが書かれたトリガー行）は、Issueの本文には含めない**でください。
* 1行目はこれまで通り `issue_title = generate_issue_title(...)` でタイトルを生成するためだけに使用します。

### ③ コメント定型部分（プレフィックス）の除去
* 2行目以降の各行について、生のPythonコメントの文字列（例: `        # ここでは...`）をそのまま出力するのではなく、**行頭の空白（インデント）、`#` 記号、およびその直後の空白を削除**（ストリップ）したクリーンなテキストに変換してから `issue_body_lines` に追加してください。
* 具体的には、各行に対して `.lstrip(" \t#")` や `.lstrip()` のような処理を適用してください。

## 4. 期待する修正後のコードイメージ（抜粋）

`main()` 関数内のループ部分を以下のように変更してください（他の機能や既存実装は崩さないこと）。

```python
    for i, data in enumerate(extracted_blocks_flat, 1):
        filepath = data["filepath"]
        block = data["block"]
        
        issue_title = generate_issue_title(block["content"], author_name, filepath)
        
        file_permalink = f"{repo_url}/blob/{commit_hash}/{filepath}#L{block['line']}"
        
        # Issue本文の構成
        issue_body_lines = []
        
        # 1行目はスキップし、2行目以降のコメント記号とインデントを取り除く
        for line in block['content'][1:]:
            # 行頭の空白と '#' を取り除き、さらにその直後の空白を取り除く
            clean_line = line.lstrip(" \t#").lstrip(" \t")
            issue_body_lines.append(clean_line)
            
        issue_body_lines.append("") # 空行を挿入
        issue_body_lines.append(f"🔗 [{filepath} (Line {block['line']})]({file_permalink})")
        
        issue_body = "\n".join(issue_body_lines)
        
        print(f"🚀 [{i}/{total_blocks}] Issueを起票中: {issue_title}")
```
