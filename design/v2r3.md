### 指示書: `gip` のGitea API起票時のラベル付与機能の実装

あなたは優秀なPythonエンジニアです。
提供された `src/gip/main.py` のコード を修正し、`GiteaPublisher` クラスにおいてIssue起票時にラベル（`gip`）が正しく付与されるように改修してください。

#### 1. 背景と課題

現在、`GithubPublisher` では `gh` コマンドを経由して文字列のままラベル（`gip`）が付与されていますが、`GiteaPublisher` の `create_issue` メソッドでは受け取った `labels` 引数がペイロードに含まれておらず、機能していません。
また、GiteaのIssue作成APIでは、ラベルを「名前（文字列の配列）」ではなく「ラベルID（整数の配列）」で指定する仕様となっています。そのため、事前にAPIを叩いてラベル名からIDを解決するステップが必要です。

#### 2. 実装要件

`main.py` 内の `GiteaPublisher` クラス を以下の仕様で書き換えてください。

**要件 A: ラベルID取得メソッドの追加**
`GiteaPublisher` クラス内に、以下のメソッドを追加してください。

* **メソッド名:** `_get_label_ids(self, owner: str, repo: str, label_names: list[str]) -> list[int]`
* **処理内容:**
1. `GET /repos/{owner}/{repo}/labels` エンドポイントを叩き、リポジトリに存在するラベルの一覧（JSON配列）を取得する。
2. 取得した一覧の中から、`label_names` に含まれる名前を持つラベルを探し、その `id` (整数) をリストに詰めて返す。
3. 通信エラー等が発生した場合は例外を投げずにエラーをprint（`⚠️ Giteaラベル取得エラー: ...`）し、空のリスト `[]` を返す（ラベル付与に失敗してもIssueの起票自体は継続させるため）。



**要件 B: `create_issue` メソッドのペイロード修正**
既存の `GiteaPublisher.create_issue` メソッド を以下のように修正してください。

1. `parse_owner_repo` で owner と repo を取得した後、先ほど追加した `_get_label_ids` メソッドを呼び出し、引数の `labels` (例: `["gip"]`) をラベルIDのリストに変換する。
2. POSTリクエスト用の `payload` 辞書に `"labels": label_ids` を追加する。

#### 3. 修正後の `GiteaPublisher` クラスの期待されるコード構造

エージェントは以下のコード構造を参考に、既存の実装 を安全に置き換えてください。

```python
class GiteaPublisher(BasePublisher):
    def __init__(self, token: str, base_url: str, target_remote_url: str):
        self.token = token
        self.base_url = base_url
        self.target_remote_url = target_remote_url

    def _get_label_ids(self, owner: str, repo: str, label_names: list[str]) -> list[int]:
        if not label_names:
            return []
            
        url = f"{self.base_url.rstrip('/')}/repos/{owner}/{repo}/labels"
        req = urllib.request.Request(url, method="GET")
        req.add_header("Authorization", f"token {self.token}")
        req.add_header("Accept", "application/json")
        
        try:
            with urllib.request.urlopen(req) as response:
                labels_data = json.loads(response.read().decode("utf-8"))
                label_ids = [
                    label.get("id") for label in labels_data 
                    if label.get("name") in label_names
                ]
                return label_ids
        except Exception as e:
            print(f"⚠️ Giteaラベル取得エラー: {e}")
            return []

    def create_issue(self, title: str, body: str, labels: list[str]) -> str:
        owner, repo = parse_owner_repo(self.target_remote_url)
        label_ids = self._get_label_ids(owner, repo, labels)
        
        url = f"{self.base_url.rstrip('/')}/repos/{owner}/{repo}/issues"
        
        payload = {
            "title": title,
            "body": body,
            "labels": label_ids  # 修正箇所: 解決したIDのリストを渡す
        }
        
        data = json.dumps(payload).encode("utf-8")
        req = urllib.request.Request(url, data=data, method="POST")
        req.add_header("Authorization", f"token {self.token}")
        req.add_header("Content-Type", "application/json")
        req.add_header("Accept", "application/json")
        
        try:
            with urllib.request.urlopen(req) as response:
                res_data = json.loads(response.read().decode("utf-8"))
                return res_data.get("html_url", "")
        except urllib.error.HTTPError as e:
            err_body = e.read().decode('utf-8')
            print(f"❌ Gitea API Error ({e.code}): {err_body}")
            sys.exit(1)
        except Exception as e:
            print(f"❌ Gitea Error: {e}")
            sys.exit(1)

```

この修正により、Issue作成時にGitea上で事前に作成された「gip」ラベルが正しくアサインされるようにしてください。
